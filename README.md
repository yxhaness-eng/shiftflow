# ShiftFlow — Персональный календарь смен и жизни 🐾

**ShiftFlow** — это эстетичное, уютное и полностью автономное веб-приложение (PWA) в эстетике **Pinterest / Scrapbook / Cozy Journal**, объединяющее:
- 🗓️ Автоматический расчет графика смен (базовый 7/0 с чередованием точек 2 через 2, поддержка произвольного количества точек и длительностей).
- 🔄 Систему подмен с фиксацией исходной и фактической точки.
- ✏️ Ручное редактирование календаря с двумя режимами (Вариант А: только этот день; Вариант Б: изменение цикла с выбранной даты).
- 📝 Личные заметки и теги событий (Романтика, Отдых, Встреча, Настроение и др.).
- 🐱 95 акварельных стикеров котиков с прозрачным фоном, сохранением координат, угла поворота и масштаба.
- 🎨 3 темы оформления (Cozy Cats, Lavender Journal, Pastel Scrapbook).
- 📊 Аналитику и статистику смен за месяц с журналом истории.
- 💾 Локальное хранение в IndexedDB, экспорт/импорт в JSON и полную поддержку офлайн-режима (PWA).

## 🚀 Быстрый запуск

### Требования
- Node.js (v18+)
- npm

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
После запуска откройте ссылку в браузере (по умолчанию `http://localhost:5173/`).

### 3. Запуск unit-тестов
```bash
npm test
```
Все 24 unit- и сценарных теста будут выполнены в Vitest.

### 4. Сборка для публикации (Production Build)
```bash
npm run build
```
Готовые оптимизированные файлы и Service Worker будут созданы в папке `dist/`.

Для предварительного просмотра собранного проекта:
```bash
npm run preview
```

## 📱 Установка PWA на телефон

Приложение спроектировано в первую очередь для мобильных устройств и работает автономно без интернета.

### На iPhone / iPad (Safari)
1. Откройте сайт в Safari.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. Иконка ShiftFlow с акварельным котиком появится на домашнем экране.

### На Android (Chrome)
1. Откройте сайт в Chrome.
2. Вверху или внизу экрана появится баннер **«Установить приложение»** (либо нажмите кнопку «Установить» в шапке ShiftFlow).
3. Или откройте меню браузера (три точки) и выберите **«Установить приложение»** / **«Добавить на главный экран»**.

## 🌐 Публикация на бесплатном хостинге

Приложение настроено с относительными путями (`base: './'`), поэтому оно корректно работает как в корневом каталоге, так и во вложенных подкаталогах.

### Вариант 1: Cloudflare Pages (Рекомендуется)
1. Создайте проект в [Cloudflare Pages](https://dash.cloudflare.com/).
2. Подключите ваш Git-репозиторий или просто перетащите папку `dist/` через интерфейс Direct Upload.
3. Если подключаете Git:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`

### Вариант 2: GitHub Pages
1. В репозитории на GitHub перейдите в **Settings -> Pages**.
2. В разделе **Build and deployment** выберите **GitHub Actions**.
3. Создайте workflow `.github/workflows/deploy.yml`:
   ```yaml
   name: Deploy to GitHub Pages
   on:
     push:
       branches: [main]
   jobs:
     deploy:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with:
             node-version: 20
         - run: npm ci
         - run: npm run build
         - uses: peaceiris/actions-gh-pages@v3
           with:
             github_token: ${{ secrets.GITHUB_TOKEN }}
             publish_dir: ./dist
   ```

## 📋 Реализованные функции

- [x] **Автоматический расчет графика 7/0**:
  - Точка отсчета: 1 ноября 2026 г. (настраиваемая).
  - Первоначальный выбор первой точки (Точка А или Точка Б).
  - Чередование 2 дня через 2 дня без сбоев на стыках месяцев и високосных лет.
  - Поддержка произвольного числа точек и произвольной продолжительности.
- [x] **Календарь (Главный экран)**:
  - Месячная сетка, неделя с понедельника.
  - Переключение месяцев, быстрый переход к текущему дню («Сегодня»).
  - Отображение плашки рабочей точки с цветом.
  - Отображение подмен со специальным маркером (`🔄`).
  - Отображение индикатора личных заметок.
  - Отображение наклеенных стикеров.
- [x] **Редактирование дней (Day Editor)**:
  - Панель редактирования по клику на любую дату.
  - **Вариант А**: изменить рабочую точку только для этого дня.
  - **Вариант Б**: изменить этот день и перезапустить цикл чередования с этой даты.
  - Система подмен с сохранением исходной и фактической точки.
  - Смена статуса дня («Работа», «Выходной», «Отпуск», «Больничный»).
  - Личные заметки и чипы событий (Романтика, Отдых, Встреча, Настроение и др.).
  - Добавление и интерактивное позиционирование стикеров (сдвиг, вращение, масштаб, удаление).
  - Кнопка возврата к графику по умолчанию.
- [x] **95 акварельных стикеров котиков**:
  - Извлечены из 3 предоставленных референсных листов с удалением фона.
  - Разложены в `public/stickers/` с манифестом `manifest.json`.
  - Категории: Повседневная жизнь, Хобби, Отдых, Настроение, Погода, Природа, Романтика, Другое.
  - Каталог стикеров с фильтрацией, поиском и возможностью наклеить на выбранную дату.
  - Постоянное сохранение координат и угла наклона в IndexedDB.
- [x] **Темы оформления**:
  - **Cozy Cats**: молочные и бежевые оттенки, акварельный уют.
  - **Lavender Journal**: лавандовый ежедневник, бумажные фактуры.
  - **Pastel Scrapbook**: коллажная пастель, пудровый и шалфейный.
- [x] **Статистика**:
  - Расчет рабочих дней, выходных, подмен и количества стикеров за любой выбранный месяц.
  - Распределение смен и отработанных часов по рабочим точкам.
  - Журнал истории изменений (аудит всех действий).
- [x] **Настройки и резервное копирование**:
  - Редактирование списка рабочих точек, названий, цветов и часов работы.
  - Настройка последовательности и шагов цикла.
  - Экспорт всей базы в JSON-файл (`shiftflow-backup-YYYY-MM-DD.json`).
  - Импорт JSON-файла с валидацией схемы.
  - Полный сброс базы с подтверждением.
- [x] **PWA и автономность**:
  - Сервис-воркер кэширует всё приложение (включая все 95 стикеров).
  - Работает 100% автономно без подключения к сети.
  - Web App Manifest с иконками 192x192 и 512x512.
- [x] **Надежность и тесты**:
  - 24 автоматизированных unit- и сценарных теста.
  - Защита от таймзонных ошибок и DST благодаря целочисленному календарному расчету.

├── data/                # Манифест 95 стикеров и категории

│   ├── SettingsPage/
│   ├── StatisticsPage/
│   └── StickersPage/

│   ├── scheduleEngine.ts # Математика графика и расчет дат
│   ├── scheduleEngine.test.ts # Unit-тесты расписания

├── types/               # TypeScript интерфейсы
